# Trivia Night — CLAUDE.md

## Stack
- Python 3.11+, PyQt6, rapidfuzz, pytest, SQLite (stdlib)
- No external API calls in v1.0

## Project Structure
- `game/` — state machine, engine, player model, scorer, timer
- `ui/` — PyQt6 screens and widgets
- `answering/` — fuzzy answer evaluator
- `data/` — SQLite DB + JSON seed files + seeder script
- `assets/` — sounds, music (added Session 7)

## Database
- `data/questions.db` — generated by `python data/seed/seeder.py`
- Schema in `data/db.py` — run migration before anything else
- Never hand-edit the DB; regenerate from JSON seed files

## Question Curation Rule
Canonical answers must be short specific terms: proper nouns, dates, named entities.
- Good: "Who invented the telephone?" → answer: "Alexander Graham Bell"
- Bad: "Why did Rome fall?" → fuzzy match will fail on essay answers

## Answer Evaluation
- `answering/evaluator.py` uses rapidfuzz `token_sort_ratio` + keyword fallback
- Threshold: 78 (tunable)
- Keyword fallback: partial_ratio ≥ 85 on any keyword

2. 3 remaining genres (arts, people, music) — 225 more questions
3. Game engine (state machine, player, scorer, timer)
4. Core UI scaffold (welcome, board, scoreboard)
5. Question screen + timer widget
6. Answer evaluation + round logic
7. Audio + polish
8. QA + ship

## Key Decisions
- Tie-breaking: Sudden Death (one random Q, first correct answer wins)
- Pause: Escape key, max 2/player/round, timer suspends
- Input validation: names 2–20 chars ASCII; answers max 200 chars
- Error handling: DB missing → dialog + exit; audio missing → log + mute; QMM unavailable → try pygame, then silent
